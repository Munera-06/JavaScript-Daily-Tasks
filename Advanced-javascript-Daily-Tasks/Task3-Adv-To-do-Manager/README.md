# Task 3 – Advanced JavaScript To-do Manager

## 📌 Project Description
The Advanced JavaScript To-do Manager is a task management application developed using HTML, CSS, and JavaScript. It helps users organize their daily activities by adding, managing, and tracking tasks.

## 🚀 Features
- Add new tasks.
- View all added tasks.
- Mark tasks as completed.
- Delete tasks.
- User-friendly interface.
- Dynamic task management using JavaScript.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
