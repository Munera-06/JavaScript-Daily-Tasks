# Day 20 – JavaScript Practice Tasks

## Project Overview
This project contains JavaScript practice tasks created as part of my daily learning journey. These tasks focus on password strength validation and calculating shopping bills using JavaScript.

## Technologies Used
- HTML5
- JavaScript

## Folder Structure
```text
Day_20_Tasks/
├── Task1/
│   └── Password Strength Checker
└── Task2/
    └── Shopping Bill Calculator
```

## Tasks

### 1. Password Strength Checker
- Checks the strength of a password based on specific conditions.
- Validates password requirements such as length and character types.
- Displays the password strength based on the validation results.

### 2. Shopping Bill Calculator
- Calculates the total bill based on shopping details.
- Uses arithmetic operations to calculate the amount.
- Displays the final bill based on the entered values.
