# Day 21 – JavaScript Practice Tasks

## Project Overview
This project contains JavaScript practice programs created as part of my daily learning journey. These tasks focus on generating number patterns and calculating electricity bills using user input.

## Technologies Used
- HTML5
- JavaScript

## Folder Structure
```text
Day_21_Tasks/
├── Task1-Number-Pyramid/
└── Task2-Electricity-Bill-Calculator/
```

## Tasks

### 1. Number Pyramid
- Prints a pyramid pattern using numbers.
- Uses nested loops to arrange numbers in rows.
- Practices loop control and pattern generation.

### 2. Electricity Bill Calculator
- Calculates the electricity bill based on units consumed.
- Uses conditional statements to apply the relevant charges.
- Displays the calculated bill amount.

## Concepts Practiced

- For Loops and Nested Loops
- Conditional Statements
- User Input
- Mathematical Operations
- DOM Manipulation
