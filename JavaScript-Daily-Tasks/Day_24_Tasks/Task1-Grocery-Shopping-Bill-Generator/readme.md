# Task 1 – Grocery Shopping Bill Generator

## Project Overview
The Grocery Shopping Bill Generator is a JavaScript-based project that calculates the total cost of grocery items based on the entered details. It helps practice basic calculations and user input handling through an interactive webpage.

## Technologies Used
- HTML5
- JavaScript

## Folder Structure
```text
Task1-Grocery-Shopping-Bill-Generator/
├── index.html
├── script.js
└── Output/
```

## Features
- Accepts grocery item details from the user.
- Calculates the total shopping amount.
- Displays the generated bill on the webpage.
- Provides an interactive user interface.

## Files Description

### 1. index.html
- Creates the webpage structure.
- Provides the input fields and display area.
- Connects the JavaScript file to the webpage.

### 2. script.js
- Handles user input.
- Performs bill calculations.
- Displays the final shopping bill.

### 3. Output
- Contains screenshots of the project output.

## Concepts Practiced
- JavaScript Variables and Functions
- User Input Handling
- Arithmetic Operations
- DOM Manipulation
- Event Handling
- Dynamic Output Display

Improved my understanding of JavaScript calculations and DOM manipulation by creating a practical grocery billing application.
