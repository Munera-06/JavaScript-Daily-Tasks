# Day 25 – JavaScript Daily Tasks

## Project Overview
This project contains JavaScript applications designed to practice calculations, user input handling, and conditional logic through real-world examples.

## Technologies Used
- HTML5
- JavaScript

## Tasks Included

### Task 1: Bus Ticket Fare Calculator
**Folder:** `Task1-Bus-Ticket-Fare-Calculator`

- Accepts passenger and journey details from the user.
- Calculates the bus ticket fare based on the entered details.
- Displays the total ticket cost.
- Practices arithmetic operations, conditional statements, and user input handling.

### Task 2: Monthly Budget Tracker
**Folder:** `Task2-Monthly-Budget-Tracker`

- Accepts monthly income and expense details from the user.
- Calculates total expenses and remaining balance.
- Displays a summary of the monthly budget.
- Practices arithmetic operations, functions, and conditional statements.

## Concepts Practiced
- Variables and data types
- Functions
- User input handling
- Arithmetic operations
- Conditional statements
- DOM manipulation
- Event handling

## Learning Outcome
These tasks improve JavaScript problem-solving skills by applying programming concepts to everyday activities such as calculating travel costs and managing monthly expenses.
