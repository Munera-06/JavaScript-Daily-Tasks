# Day 04 – JavaScript Tasks

## 📌 Project Overview

This is my Day 04 JavaScript Daily Task, created to practice JavaScript programming concepts through simple problem-solving tasks.

This task includes two JavaScript programs:

* Grade Calculation
* Factorial Calculation

Each task focuses on understanding JavaScript logic, conditions, functions, and basic programming operations.

## 📝 Task 1 – Grade Calculation

The first task focuses on calculating and displaying a grade based on the given marks.

JavaScript is used to:

* Get the required input
* Check the given marks
* Apply conditional statements
* Determine the appropriate grade
* Display the result

### Concepts Practiced

* Variables
* User input
* Conditional statements
* Comparison operators
* Functions
* Output display
