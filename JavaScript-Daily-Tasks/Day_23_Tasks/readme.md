# Day 23 – JavaScript Practice Tasks

## Project Overview
This project contains JavaScript practice programs focused on ATM cash withdrawal and employee salary calculation. These tasks help improve logical thinking, conditional handling, and mathematical problem-solving skills.

## Technologies Used
- HTML5
- JavaScript

## Folder Structure
```text
Day_23_Tasks/
├── Task1-ATM-Cash-Withdrawal/
└── Task2-Employee-Salary-Calculator/
```

## Tasks

### 1. ATM Cash Withdrawal
- Simulates a basic ATM cash withdrawal process.
- Checks the available balance and requested withdrawal amount.
- Displays the result based on the withdrawal conditions.

### 2. Employee Salary Calculator
- Calculates an employee's salary based on the entered details.
- Uses arithmetic operations to calculate salary components.
- Displays the calculated salary.

## Concepts Practiced
- JavaScript Variables and Functions
- Conditional Statements
- Arithmetic Operators
- User Input
- DOM Manipulation
- Basic Validation
- Problem-Solving

Improved my understanding of JavaScript logic, input validation, and calculations by creating practical programs based on real-world scenarios.
