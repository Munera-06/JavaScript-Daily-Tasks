# Day 14 – JavaScript Loop Programs 2

## Project Overview

This project contains JavaScript loop practice programs created as part of my daily learning journey. These tasks focus on number patterns, summation, and printing even and odd numbers.

## Technologies Used

* HTML5
* JavaScript

## Tasks

### 1. Reverse Number Pattern

* Prints numbers in a reverse pattern.
* Uses nested loops to create the pattern.
* Practices loop control and number sequences.

### 2. Sum of 1 to N

* Calculates the sum of numbers from 1 to N.
* Uses a loop to add numbers step by step.
* Practices counters and accumulation.

### 3. Print Even Numbers

* Prints even numbers within a given range.
* Uses a loop and condition to identify even numbers.
* Practices conditional statements.

### 4. Print Odd Numbers

* Prints odd numbers within a given range.
* Uses a loop and condition to identify odd numbers.
* Practices number checking.
