# Day 18 – JavaScript Array Programs 2

## Project Overview

This project contains JavaScript array practice programs created as part of my daily learning journey. These tasks focus on sorting arrays, counting even and odd numbers, and finding a missing number.

## Technologies Used

* HTML5
* JavaScript

## Tasks

### 1. Ascending Order

* Sorts the elements of an array in ascending order.
* Arranges numbers from the smallest to the largest.
* Practices array sorting methods.

### 2. Descending Order

* Sorts the elements of an array in descending order.
* Arranges numbers from the largest to the smallest.
* Practices array sorting and comparison.

### 3. Even and Odd Count

* Counts the number of even and odd elements in an array.
* Checks each array element using a condition.
* Practices loops and conditional statements.

### 4. Missing Number

* Finds the missing number from a sequence of numbers.
* Compares the given array with the expected number sequence.
* Practices array traversal and mathematical operations.
