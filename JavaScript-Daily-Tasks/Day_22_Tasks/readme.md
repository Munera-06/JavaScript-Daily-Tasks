# Day 22 – JavaScript Practice Tasks

## Project Overview
This project contains JavaScript practice programs focused on calculating shopping discounts and electricity bills with late fees. These tasks help improve logical thinking and practical problem-solving skills.

## Technologies Used
- HTML5
- JavaScript

## Folder Structure
```text
Day_22_Tasks/
├── Task1-Shopping-Discount-Calculator/
└── Task2-Electricity-Bill-with-Late-Fee/
```

## Tasks

### 1. Shopping Discount Calculator
- Calculates the discount based on the shopping amount.
- Determines the final price after applying the discount.
- Practices conditional statements and mathematical operations.

### 2. Electricity Bill with Late Fee
- Calculates the electricity bill based on units consumed.
- Adds a late fee when applicable.
- Displays the total payable amount.

## Concepts Practiced

- User Input
- DOM Manipulation
- Basic Calculations
