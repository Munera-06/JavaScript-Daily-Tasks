# Task-01: Positive or Negative Number 

## 📌 Task Description

Create a simple JavaScript program that checks whether the entered number is **Positive**, **Negative**, or **Zero**.

The user enters a number in the input field and clicks the **Check** button to display the result.

## 🛠️ Technologies Used

* HTML
* JavaScript

## 📂 Project Structure

```text
Task-01-Positive-Negative/
│
├── index.html
├── script.js
└── Output_Screenshots/
```

## 💡 How It Works

1. Enter a number in the input field.
2. Click the **Check** button.
3. JavaScript checks the entered number.
4. The result is displayed on the webpage.

### Conditions

```text
Number > 0  → Positive
Number < 0  → Negative
Number = 0  → Zero
```

## 🖥️ Features

* Simple and beginner-friendly interface
* Accepts number input
* Checks Positive, Negative, and Zero
* Displays the result directly on the webpage

## ▶️ How to Run

1. Download or clone the repository.
2. Open the `Task-01-Positive-Negative` folder.
3. Open `index.html` in a web browser.
4. Enter a number.
5. Click **Check**.
