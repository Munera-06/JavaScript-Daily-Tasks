# Day 17 – JavaScript Number Programs

## Project Overview

This project contains JavaScript number-based practice programs created as part of my daily learning journey. These tasks focus on mathematical operations, number sequences, and checking number properties.

## Technologies Used

* HTML5
* JavaScript

## Folder Structure

```text
Day_17_Tasks/
└── Number-Program/
    ├── Tasks1-GCD-of-Two-Numbers/
    ├── Tasks2-Fibonacci Series/
    └── Tasks3-Prime Number/
```

## Tasks

### 1. GCD of Two Numbers

* Finds the Greatest Common Divisor (GCD) of two numbers.
* Uses loops and mathematical operations.
* Practices number comparison and division.

### 2. Fibonacci Series

* Generates the Fibonacci series for a given number of terms.
* Uses loops and variable updates.
* Practices number sequences and iteration.

### 3. Prime Number

* Checks whether a given number is a prime number.
* Uses a loop to check the factors of the number.
* Practices conditional statements and number checking.
