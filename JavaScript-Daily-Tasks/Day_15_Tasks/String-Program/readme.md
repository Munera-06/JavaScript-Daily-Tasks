# Day 15 – JavaScript String Programs

## Project Overview

This project contains JavaScript string practice programs created as part of my daily learning journey. These tasks focus on counting digits, removing spaces, and accessing characters in a string.

## Technologies Used

* HTML5
* JavaScript

## Folder Structure

```text
Day_15_Tasks/
└── String-Program/
    ├── Tasks1-Count-Digits/
    ├── Tasks2-Remove-Spaces/
    └── Tasks3-First-Character/
```

## Tasks

### 1. Count Digits

* Counts the number of digits in a given string.
* Uses string traversal and character checking.
* Practices loops and conditional statements.

### 2. Remove Spaces

* Removes spaces from a given string.
* Uses JavaScript string methods.
* Practices string manipulation.

### 3. First Character

* Finds and displays the first character of a given string.
* Uses string indexing.
* Practices basic string operations.
