## 🔄 Task 3 – Palindrome

The third task focuses on checking whether a given value is a palindrome.

A palindrome is a value that remains the same when it is read forward and backward.

JavaScript is used to process the given value and check whether it satisfies the palindrome condition.

### Concepts Practiced

* Strings
* String manipulation
* Reverse logic
* Conditional statements
* Comparison
* Functions
* Basic problem-solving

## 🧮 Task 4 – Cube of a Number
